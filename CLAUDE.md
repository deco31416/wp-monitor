# Adaptador para Claude Code

- Para tareas de descubrimiento, cambios que afecten varios módulos, contratos, datos, seguridad, infraestructura o releases, comienza en Plan Mode y lee `docs/AI_ENGINEERING_PROTOCOL.md`.
- Trata la memoria automática como ayuda, nunca como fuente de verdad del repositorio.
- Antes de editar, resume el modo seleccionado, el alcance y la evidencia base.
- No uses `--dangerously-skip-permissions` ni desactives controles para acelerar una tarea.
- Cuando una regla deba ejecutarse obligatoriamente en cada commit o edición, recomienda un hook, linter o control de CI; no finjas que una instrucción textual es una garantía técnica.
